# 已学习策略的实际选择记录

这里固定使用种子2700000，分别执BLUE和RED导出同一PPO检查点的实际决策，没有挑选有利结果。

- BLUE：56次决策，终局20比40；公开比分在游戏时间1074、1480发生变化。
- RED：57次决策，终局50比10；公开比分在1314、1492、1566发生变化。
- 两局都在游戏时间1800正常结束。它们是学习结果的观察样本，整体强度请看独立多种子评测。

每个席位都有三种文件：Markdown用于快速浏览已选动作和对应概率；CSV包含每次决策的全部候选动作、概率、选择标记和当时公开双方总分；JSON还包含可重建的完整公开观察及空间上下文。静态地图只保存一次，避免重复占用空间。

比分变化是复盘时的定位标记，不代表某一步一定是最佳动作或导致了变化。网络采用随机抽样策略，已选动作不一定是概率最高的动作。这些记录展示训练后模型实际做了什么，没有添加手写战术解释。

使用方法和复现命令见[回放导出说明](../replay.md)。模型SHA256：`895d827c1a311e8c04ef92a9626fdb01c62376d69594ae6dbbd7746e0b8c9486`。

公开传输使用无损压缩的 `.json.gz`。下载后运行 `python -m gzip -d 文件名.json.gz` 即可恢复 JSON；压缩前后文件大小和 SHA256 记录在 `compressed-manifest.json`。CSV 和 Markdown 可直接阅读。
