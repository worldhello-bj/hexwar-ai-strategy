# 2026-10-14 终局计分学习基线

## 实验设置

- 场景：仓库合成 `samples/demo`，固定地图，双方视角迷雾。
- 输入：本方信息、当前可见对手信息、最后目击记录、公开总分。
- 奖励：正常终局的本方原始总分，中间每步为零。
- 算法：精确观察表格、首次访问蒙特卡洛；探索率0.2，随机种子7。
- 每局1800游戏秒，外部预算1000步；双方轮流行动。
- 训练先20局，再从检查点续跑80局，总计100局。
- 训练种子0—99；随机对手对照使用1000100—1000103，每个种子各执一方，共8场。

这轮完成了环境、终局计分、双边学习、检查点续跑和对照赛闭环。对照结果没有显示当前学习表优于随机对手；增加训练局数也没有在这8场对照中带来改善。精确观察表格不能对新局面泛化，双方共同变化还使学习目标随训练变化。下一阶段应更换具有泛化能力的策略模型并扩大独立评测，不能把反复续跑当作实力提升。

20局与100局完整检查点均已随仓库保存；100局备份位于 `artifacts/selfplay/checkpoint-100-20261014.json.gz`，相邻 `checkpoint-100-20261014.metadata.json` 记录压缩前后 SHA256、文件大小及运行配置。JSON报告记录每局种子、正常结束原因、最终分数及配置。随机过程的独立种子并不等于不同地图；这些结果只描述当前示例场景。

## 共享特征神经网络基线

进一步增加通用 JSON 编码的观察—动作神经网络，用 REINFORCE 和观察值基线学习，奖励仍为原始终局本方总分。对手固定为均匀随机策略，学习方按场次交替席位。没有手写战术特征或动作奖励。

模型设置：2048特征桶、32维向量、Adam学习率0.001、每4个正常结束场次更新一次、种子13。先4局试运行，再续跑96局，累计100局、25次更新，全部正常结束。追加96局及评测耗时188.85秒，进程峰值常驻内存129.30MB。

预留种子2000000和2000001、各执双方，共4场：初始模型与100局模型均为1胜1平2负，平均本方得分27.5。这个小样本没有显示差异。下一步使用事先固定的一组全新种子作独立诊断，不利用结果调整本轮模型。

使用事先固定的新种子2100000—2100031，每个种子各执双方。初始模型和训练100局模型各对随机对手运行64场，总计128场，225.39秒，全部正常结算。评测不更新参数。

按同一种子的两个席位先求均值，训练后本方得分提升1.25分，32组种子的描述性标准误为1.402。观察到的提升仍小于当前样本波动，不能据此认定稳定提升。胜场增加8场主要伴随平局减少，负场数不变。这比只看胜率更完整地描述了变化。

完整结果见 `neural-fresh-32pairs-20261014.json`。新工具 `python -m tools.evaluate_neural_checkpoint` 支持冻结检查点的全新种子评测；拒绝与训练种子和既有预留种子重叠，保存原检查点哈希并验证文件及模型状态不变。
